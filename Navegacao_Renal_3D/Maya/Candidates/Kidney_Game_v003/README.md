# Kidney Game v003

Revisão do rim ativo que substitui o alinhamento provisório do Marco 3.1 por
uma junção geométrica curta com o ureter esquerdo Meshy.

Arquivos principais:

- `Source/Urinary_System_Assembly_v003.ma`: cena completa para inspeção no Maya;
- `Source/Kidney_Master_v003.ma`: rim v003 editável isolado;
- `Exports/Kidney_Game_v003.fbx`: exportação usada pelo Unity;
- `Documentation/validation_report.json`: validação geométrica;
- `Documentation/assembly_report_v003.json`: alinhamento da montagem;
- `Previews`: imagens de revisão do modelo isolado.

A v002 não foi sobrescrita. A cena de montagem usa centímetros e registra a
escala visual `5×` aplicada pelo Unity.
